## FR — À propos

**Pokédex** est une application mobile Android développée dans un contexte académique.  
Elle agit comme une encyclopédie Pokémon en s’appuyant sur **PokeAPI** pour récupérer les données, avec un accent sur la navigation, la recherche et l’organisation des informations.

L’application permet de consulter des Pokémon, d’accéder à leurs caractéristiques et de gérer une liste de favoris stockée localement.

### Technologies
- Java  
- Android Studio  
- PokeAPI (REST)  
- SQLite  
- Architecture Android (Activities / Fragments)

## ENG — About

**Pokédex** is an Android mobile application developed in an academic context.  
It functions as a Pokémon encyclopedia using **PokeAPI** to retrieve data, with a focus on navigation, search, and structured information display.

The app allows users to browse Pokémon, view detailed stats, and manage a locally stored favorites list.

### Technologies
- Java  
- Android Studio  
- PokeAPI (REST)  
- SQLite  
- Android architecture (Activities / Fragments)
